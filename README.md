## 🧠 À propos de moi

Je suis un **développeur web** et **ingénieur en IA & Big Data** passionné par la transformation des données brutes en solutions utiles pour les entreprises.

Mon objectif : **prendre des données, les étudier et les rendre utiles** pour créer de la valeur réelle.

- 🌐 Je développe des applications web modernes avec **Django**, **Bootstrap** et **Django REST Framework**
- 🧪 Je conçois des modèles de **Machine Learning** et **Deep Learning**
- 📈 Je transforme les données en tableaux de bord exploitables avec **Power BI** et **Excel**
- 🗄️ Je maîtrise les bases de données **PostgreSQL** et **MySQL**
- ⚡ Je travaille sur du Big Data avec **Spark (PySpark)**
- 🚀 Actuellement en train d'apprendre **FastAPI** pour créer des API modernes et performantes
